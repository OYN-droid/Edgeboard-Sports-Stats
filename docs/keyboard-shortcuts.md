# Keyboard shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘K` / `Ctrl+K` | Open or close global EdgeBoard search |
| `↑` / `↓` | Move through command-palette or autocomplete results |
| `Enter` | Open the selected result |
| `Escape` | Close the active palette, dialog, or result list |
| `Tab` / `Shift+Tab` | Move through interactive controls |
| Arrow keys | Move within supported tablists and segmented controls |
| `Home` / `End` | Move to the first or last research mode |

All essential actions have visible buttons and do not require a shortcut, pointer, drag gesture, or hover.
