# Getting started

EdgeBoard runs in sample mode without provider credentials. The **Sample** badge and Data Status dialog identify that mode; sample values must not be described as live.

1. Choose **Stats**, **Betting**, or **Both**. The mode changes presentation, not the meaning of source data.
2. Select a sport or league, or keep **All Sports** for cross-sport discovery.
3. Open a Story, profile, market, visualization, or Historical Explorer item, or ask **Edge Intelligence** a structured question.
4. Open **Edge Trust** whenever you need freshness, coverage, source agreement, and Research Quality details.
5. Save work to the local **Workspace**. Local storage is device-specific and is not cloud backup.

Press `⌘K` on macOS or `Ctrl+K` elsewhere to search canonical profiles, Stories, History, Edge Markets, local Workspace items, and commands.

## Important labels

- **Observed fact** comes from retained source rows.
- **Projection** is model output and remains separate from historical hit rate.
- **Confidence** describes model signal agreement; it is not win probability.
- **Research Quality** summarizes evidence quality; it is not betting confidence or probability.
- **Scenario assumption** and **future simulation** are sandbox inputs, not predictions.
